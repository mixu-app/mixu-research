# Mixu Research

Mixu（谜序）的研究仓：文献、实验、可复现的证据，以及将来 Mixu 自己发表的论文。

**这个仓库不存放书籍正文。** 只存元数据、协议、脚本、结果和引用。文本在运行时按需下载，
写入被 Git 忽略的 `corpora/cache/`。

## 为什么单独开一个仓

- 构建「随阅读进度演化的知识图谱」这件事本身值得留档：哪些方法试过、失败在哪、
  用什么指标判定成功。
- 研究需要引用论文，也会产出论文；论文需要可复现的工件（协议、数据清单、结果、脚本），
  这些不属于任何一个产品仓。
- 公开：让外部可以复核我们的结论，也让研究结论独立于产品代码存在。

## 目录

| 路径 | 内容 |
|---|---|
| `corpora/` | 语料清单（元数据 + 版权推断），不含正文 |
| `papers/literature/` | 文献笔记：引用、它主张什么、与 Mixu 的关系、是否复现过 |
| `papers/ours/` | 我们自己的论文：摘要、主张、状态、工件链接 |
| `experiments/` | 每个实验一个目录：`protocol.md`、`data.md`、`results.md`、脚本 |
| `tools/` | 语料校验与抓取脚本 |

## 语料与版权

清单里每一条作品都记录了首版年份与作者卒年，`tools/check_corpus.py` 会**重新计算**它在
美国、中国、欧盟的公有领域状态，而不是相信手写的标记：

- **美国**：1930 年及更早首次出版的作品，2026 年已进入公有领域（95 年规则，每年 1 月 1 日递增）。
- **中国**：作者终生 + 50 年，自死亡后第 50 年的次年 1 月 1 日起进入公有领域。
- **欧盟**：作者终生 + 70 年。

清单里因此会看到这样的组合：柯南·道尔（1930 年卒）在美国、中国、欧盟都已公有；
阿加莎·克里斯蒂（1976 年卒）的作品**在中国仍受保护至 2026 年底**，2027 年 1 月 1 日起进入公有领域；
而在美国，她 1930 年及以前出版的作品早已公有。

三条硬规则：

1. 本仓不提交任何书籍正文、摘录或转换件。
2. 抓取脚本只从美国公有领域的来源取文件，并写入 `corpora/cache/`（被忽略）。
3. 实验报告可以引用极短片段作为证据（评论与引用目的），但不得构成实质替代。

## 研究可复现的最低要求

每个实验目录必须有：

```text
protocol.md   假设、对照组、指标、判定阈值（写成可检验的句子）
data.md       用了哪份语料/清单、版本、抓取日期、已知偏差
results.md    数值结果 + 结论 + 失败的地方
run.sh        一条命令重跑（可选，但强烈建议）
```

没有 `protocol.md` 的实验不收录；只有结论没有数值的不收录。
